SRostraLab — parche v1.1 técnica (16/10/2026)

1. Copia estos archivos sobre el proyecto conservando la estructura de carpetas.
2. Elimina manualmente, si todavía existen:
   - en/index (1).html
   - assets/js/langhint.js
3. La carpeta assets/img/original contiene una fuente JPG ya rastreada por Git. La nueva regla .gitignore evita añadir nuevos originales, pero para dejar de publicar el actual sin borrarlo de tu disco usa desde la raíz del repositorio:
   git rm --cached assets/img/original/IMG_20250629_170012.jpg
   Después haz commit. El archivo seguirá en tu carpeta local y quedará ignorado.
4. Para regenerar variantes responsive en Windows, desde la carpeta tools:
   npm install
   npm run images:responsive

No se han modificado textos editoriales visibles ni la estética general.
